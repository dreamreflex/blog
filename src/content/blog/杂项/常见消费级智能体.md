# 常见消费级智能体

随着大模型能力成熟，越来越多面向普通开发者的“AI 智能体”出现。它们通常以 CLI、桌面应用或 IDE 插件形式存在，可以直接读取代码库、执行命令、编辑文件、调用工具链。本文整理目前比较热门的消费级智能体/CLI 工具。

## 一、国外大厂

### OpenAI Codex（桌面版 + CLI）

OpenAI Codex 是 OpenAI 推出的编码智能体，既有桌面应用也有命令行版本，与 ChatGPT 账户体系打通。

- 核心能力：端到端构建功能、复杂重构、代码迁移、多智能体并行、Skills 技能扩展、Automations 后台任务。
- 终端：桌面应用（macOS / Windows）、CLI、IDE 扩展。
- 安装：`npm install -g @openai/codex`、`brew install --cask codex` 或官方安装脚本。
- 官网：https://openai.com/codex/
- 开源仓库：https://github.com/openai/codex（Apache-2.0）

### Claude Code

Anthropic 推出的终端原生智能体，强调对代码库的理解和自然语言驱动的工作流。

- 核心能力：读取/编辑文件、运行测试、处理 Git 工作流、解释复杂代码、执行例行任务。
- 安装：`curl -fsSL https://claude.ai/install.sh | bash`、`brew install --cask claude-code`、`winget install Anthropic.ClaudeCode`。
- 文档：https://code.claude.com/docs/en/overview
- 仓库：https://github.com/anthropics/claude-code

### Claude 桌面版

Claude 的通用桌面客户端，支持 AI 对话、文件上传、MCP（Model Context Protocol）扩展，也可作为日常智能体入口。

- 官网：https://claude.ai/download

## 二、国内大厂

### 阿里 Qoder

Qoder 是阿里巴巴推出的面向真实软件开发的 Agentic Coding 平台，提供桌面 IDE、CLI 和 JetBrains 插件。

- 核心能力：自主 Agent、知识引擎、Agentic Chat、Next 代码预测、并行任务编排、多智能体协作、Repo Wiki、Skills/Plugins。
- 支持模型：接入阿里云 Model Studio 等先进模型。
- 安装：`npm install -g @qoder-ai/qodercli`、官方安装脚本 `curl -fsSL https://qoder.com/install | bash`。
- 官网：https://qoder.com/
- CLI 页面：https://qoder.com/cli
- 文档：https://docs.qoder.com/
- 阿里云 Model Studio 介绍：https://www.alibabacloud.com/help/en/model-studio/qoder-agent
- 开源仓库：暂无官方开源仓库。

### 腾讯 WorkBuddy

WorkBuddy 是腾讯推出的 AI Agent 办公/工作新范式产品，常与腾讯云代码助手 CodeBuddy 结合使用，支持技能和插件扩展，并可在桌面端运行。

- 核心能力：Agent 任务执行、技能包扩展、与微信/公众号生态联动、支持远程 WebUI 访问。
- 官方入口：https://www.codebuddy.cn/agents
- CodeBuddy 主页：https://codebuddy.cn/
- 远程/网页版说明：https://github.com/vergess3/workbuddy-remote（社区远程桥接，非官方）
- 开源仓库：官方未开源。

### 小米 MiMo Code

小米 MiMo Code 是基于小米自研 MiMo 大模型（V2 / V2.5 系列）的编码智能体，强调长程任务、多模态输入与端到端编程。

- 核心能力：长程 Coding Agent（computation / memory / evolution）、多模态输入（图/音/视频）、原生联网搜索、语音合成、MTP 加速流式输出。
- 官网/模型入口：https://mimo.xiaomi.com/
- 开源仓库：MiMo Code 本身未开源；MiMo 系列模型可关注小米官方发布。

## 三、终端原生/开源智能体

### DeepSeek TUI

DeepSeek TUI 是面向 DeepSeek V4 模型的终端原生编程智能体，Rust + ratatui 构建。

- 核心能力：文件读写、Shell 执行、Git/网页搜索、子智能体、MCP 服务器、1M token 上下文、Plan/Agent/YOLO 三种模式、LSP 诊断、会话持久化。
- 安装：`npm install -g deepseek-tui`、Cargo、Homebrew 或 GitHub Release。
- 官网：https://deepseektui.homes/
- 开源仓库：https://github.com/Hmbown/DeepSeek-TUI（MIT）

### Reasonix

Reasonix 是围绕 DeepSeek 前缀缓存（prefix cache）设计的 DeepSeek 原生终端编码 Agent，强调长会话低成本。

- 核心能力：append-only 缓存优先循环（长会话 90%+ 缓存命中）、单 Go 二进制、MCP、Plan 只读模式、子智能体与 Skills、`reasonix serve` 本地浏览器 UI。
- 安装：`npm i -g reasonix@next`、`brew install esengine/reasonix/reasonix`，或桌面安装包。
- 官网：https://reasonix.io/
- 开源仓库：https://github.com/esengine/DeepSeek-Reasonix（MIT）

### Kimi Code

Moonshot AI（月之暗面）推出的 Kimi Code CLI，定位下一代 AI 编码 Agent。

- 核心能力：读改代码、运行 Shell、搜索文件、抓取网页、视频输入、子智能体、MCP、ACP 编辑器协议、插件市场。
- 默认模型：K2.7 Code。
- 安装：`curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`、`brew install kimi-code`。
- 官网：https://www.kimi.com/code
- 文档：https://moonshotai.github.io/kimi-code/en/
- 开源仓库：https://github.com/MoonshotAI/kimi-code（MIT）

### OpenCode

OpenCode 是开源 AI 编码智能体，支持终端、桌面应用和 IDE 扩展，强调隐私优先与多模型兼容。

- 核心能力：LSP 自动加载、多会话并行、会话分享链接、GitHub Copilot / ChatGPT Plus 登录、75+ 模型提供商、build/plan 双 Agent。
- 安装：`curl -fsSL https://opencode.ai/install | bash`、`npm i -g opencode-ai@latest`、`brew install anomalyco/tap/opencode`。
- 官网：https://opencode.ai/
- 开源仓库：https://github.com/anomalyco/opencode（MIT）

## 四、横向对比

| 工具 | 厂商 | 形态 | 是否开源 | 主力模型/后端 |
|---|---|---|---|---|
| OpenAI Codex | OpenAI | 桌面 + CLI + IDE | 是（CLI） | ChatGPT / OpenAI 模型 |
| Claude Code | Anthropic | CLI | 代码公开 | Claude |
| Claude 桌面版 | Anthropic | 桌面 | 否 | Claude |
| Qoder | 阿里 | 桌面 + CLI + JetBrains | 否 | 阿里云 Model Studio |
| WorkBuddy | 腾讯 | 桌面 + Web | 否 | CodeBuddy / 腾讯模型 |
| DeepSeek TUI | 社区 | CLI（TUI） | 是 | DeepSeek V4 |
| Reasonix | 社区 | CLI + 桌面 | 是 | DeepSeek |
| Kimi Code | Moonshot AI | CLI + 桌面/IDE | 是 | K2.7 Code |
| OpenCode | Anomaly | CLI + 桌面 + IDE | 是 | 多模型 |
| MiMo Code | 小米 | 桌面/CLI（内测） | 否 | MiMo V2/V2.5 |

> 注：以上链接与特性均来自各产品官网或官方 GitHub 仓库，截止 2026-06-25。部分国内产品页面为动态加载，信息以官方最新版本为准。
