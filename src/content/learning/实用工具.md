## 依赖和环境恢复列表

列表注明了新的 Windows 环境下需要安装的依赖、软件和三方组件。除另有说明外，都从官网或源码仓库下载；重装系统前，建议先在旧环境确认各工具的授权方式和数据、配置导出位置。

### 基础工具

1. [Everything](https://www.voidtools.com/)：本地文件搜索工具，按文件名秒级检索。
2. [Wox](https://www.wox.one/)（开源，[GitHub](https://github.com/Wox-launcher/Wox)）或 [uTools](https://www.utools.works/)：快捷启动条／命令面板，配合插件使用。
3. [Snipaste](https://www.snipaste.com/)：截图与贴图工具，可从 Microsoft Store 安装。
4. [Focusrite Control](https://focusrite.com/)：Focusrite 声卡（音频接口，含话筒输入）的控制软件与驱动。当前下载页为 [Focusrite Control 2](https://focusrite.com/software/focusrite-control-2)，旧型号以官网支持页对应版本为准。
5. Clash：代理客户端。原 [Dreamacro/Clash](https://github.com/Dreamacro/Clash) 仓库已归档停止维护，现在一般使用其社区延续分支 [mihomo（Clash Meta）](https://github.com/MetaCubeX/mihomo)，需要搭配自己的节点与规则配置。
6. [Kleopatra](https://www.gpg4win.org/)：GPG 密钥与证书管理的图形界面，随上文"开发套件"中的 GPG4Win 一起安装。
7. [Typora](https://typora.io/)：所见即所得的 Markdown 编辑器（付费，可试用）。
8. [UltraISO](https://www.ezbsystems.com/ultraiso/)：ISO 镜像制作与编辑。
9. [VeraCrypt](https://www.veracrypt.fr/)：文件与磁盘加密工具（TrueCrypt 的延续项目）。

### work and business

1. [Adobe Acrobat DC](https://www.adobe.com/acrobat.html)：PDF 阅读、编辑与签名，订阅制授权。
2. [Adobe Illustrator](https://www.adobe.com/products/illustrator.html)：矢量图形设计。
3. [Adobe Premiere Pro](https://www.adobe.com/products/premiere.html)：视频剪辑。
4. [Cloudflare One Client](https://developers.cloudflare.com/cloudflare-one/connections/connect-devices/warp/)（WARP）：接入 Cloudflare One 的 VPN 客户端，仅在网络侧已配置 Cloudflare One 时才有意义。
5. [OBS Studio](https://obsproject.com/)：录屏与直播推流（开源免费）。
6. [Bitwarden](https://bitwarden.com/)：开源密码管理器，可用官方托管或自建 vault。
7. [Yubico 工具集](https://www.yubico.com/support/download/)：含 Yubico Authenticator、YubiKey Manager 和智能卡组件，用于管理 YubiKey 的 OTP、FIDO 与智能卡凭据。
8. [LibreOffice](https://www.libreoffice.org/)：开源办公套件（Writer／Calc／Impress）。
9. RamDisk：内存虚拟磁盘。原列表未写明具体产品，常见实现有 [OSFMount](https://www.osfmount.com/)（可将镜像挂载为 RAM 盘）和 ImDisk 等；恢复前先确认原机安装的是哪一种，再补链接。

### Tools

1. [FastCopy](https://www.ipmsg.org/tools/fastcopy.html)：大量文件的快速复制、移动与删除。
2. [SpaceSniffer](http://www.uderzo.it/main_products/space_sniffer/)：以区块图可视化磁盘占用，方便清理空间。
3. [Zotero](https://www.zotero.org/)：文献与引用管理工具，配合浏览器插件抓取条目。
4. [向日葵（贝锐 Oray）](https://sunlogin.oray.com/)或 [ToDesk](https://www.todesk.com/)：国内可用的远程控制软件。
5. [Draw.io Desktop](https://www.drawio.com/)：流程图／架构图桌面版（开源，[GitHub](https://github.com/jgraph/drawio-desktop)）。
6. [EarTrumpet](https://eartrumpet.app/)：按应用控制多路音频输入输出，Microsoft Store 可直接安装。
7. [File Converter](https://github.com/Tichau/FileConverter)：右键菜单直接转换、压缩音视频和文档格式（开源）。
8. MemPad：加密记事本。官网在本机环境未能联网核实，安装前请从原下载渠道确认来源，勿直接处理既有的加密数据文件。
9. AltasCI CertManager：内部证书管理工具，仅通过内部渠道分发，没有公网下载地址。
10. [RustDesk](https://rustdesk.com/)：开源远程控制，可自建中继服务器。

### Develop

1. [Cursor](https://www.cursor.com/)：AI 代码编辑器。
2. [Notepad++](https://notepad-plus-plus.org/)：轻量文本／代码编辑器。
3. [VSCode](https://code.visualstudio.com/)：同上文"开发套件"。
4. [DBeaver](https://dbeaver.io/)：通用数据库客户端，配合下文 Dependencies 中的本地数据库实例使用。
5. [Tabby](https://tabby.sh/)：现代终端，可集成 SSH、WSL 与 Git Bash。
6. [OpenCode](https://opencode.ai/)：开源 AI 编程代理，以终端界面为主，另提供桌面端 GUI。

### Dependencies

1. [MSYS2](https://www.msys2.org/)：装好后再通过 pacman 安装 Clang/LLVM 工具链，用于 C/C++ 开发。
2. [Visual C++ 运行时](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)：即原列表的"VS++ Runtimes 15–22"，多数软件的 DLL 依赖来自它；x64 和 x86 两个版本建议都安装。
3. [WSL2 + Ubuntu 24.04](https://learn.microsoft.com/en-us/windows/wsl/install)：可用 `wsl --install -d Ubuntu-24.04` 或从 Microsoft Store 安装；恢复环境时注意先导出原发行版数据。
4. [uv](https://docs.astral.sh/uv/)（[GitHub](https://github.com/astral-sh/uv)）：Python 版本、虚拟环境与依赖管理。
5. [Node.js](https://nodejs.org/)：Node 运行时与 npm，按项目需要选择 LTS 版本。
6. [MongoDB Community Server](https://www.mongodb.com/try/download/community)：本地实例；恢复前先备份原数据目录。
7. [MySQL Community Server](https://dev.mysql.com/downloads/mysql/)：本地实例。
8. [Memurai](https://memurai.com/)：Windows 上的 Redis 兼容实现，作本地实例使用。
9. [Git for Windows](https://gitforwindows.org/)：包含 Git Bash，同上文"开发套件"中的 Git。
