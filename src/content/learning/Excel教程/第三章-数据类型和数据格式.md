# 第三章-数据类型和数据格式

## 1.基本格式

Excel中只有两种基本格式：数字型和文本型

数字型：参与计算，复杂渲染

文本型：文本操作（拼接，替换）

## 2.数据类型

![image-20260110175813733](./第三章-数据类型和数据格式.assets/image-20260110175813733.png)

1. 数值：参与计算，能够加减，能够求和等
2. 货币：简单货币运算
3. 会计专用：会计格式
4. 日期：年月日格式
5. 时间：时分秒格式
6. 百分比/分数：数学类型
7. 科学计数：5x10^±6
8. 文本：字符类型
9. 特殊：邮编等
10. 自定义格式：强大的工具

### 自定义格式

| 符号      | 作用                           | 举例（单元格值 3.5）            |
| --------- | ------------------------------ | ------------------------------- |
| `0`       | 必须占一位，不足补 0           | `0.00` → 3.50                   |
| `#`       | 有则显示，无则省               | `#.##` → 3.5                    |
| `?`       | 不足补空格，做对齐             | `?.?` → 3.5（小数点对齐）       |
| `.`       | 小数点                         |                                 |
| `,`       | 千位分隔符，或把数字缩 1000 倍 | `#,##0` → 3,510；`#,"k"` → 4k   |
| `%`       | 自动 ×100 加 %                 | `0%` → 350%                     |
| `E+` `E-` | 科学计数                       | `0.00E+00` → 3.50E+00           |
| `_`       | 下跳一个字符宽，用来做对齐     | `_-`                            |
| `@`       | 文本占位符                     | `"Hello "@` → Hello Tom         |
| `*`       | 重复后一个字符填满列宽         | `*-` → ---------                |
| `[颜色]`  | 中文或英文颜色名               | `[红色]0.00;[绿色]-0.00`        |
| `[条件]`  | 自定义条件                     | `[>=80]"优";[<60]"不及格";"良"` |

1. 手机号分段：000-0000-0000
   输 13812345678 → 138-1234-5678
2. 万元显示且带千位分隔：#,##0,, "万元"
   输 34567000 → 3,457 万元
3. 自动添单位并保留 2 位小数：0.00" kg"
   输 82.5 → 82.50 kg
4. 正负零三色：
   `[蓝色]#,##0.00;[红色]#,##0.00;[黑色]"–"`
5. 小写金额变大写（Excel 自带特殊代码）：
   `[DBNum2]General` → 壹贰叁肆伍陆柒捌玖
